# 🚀 System Status: Active | Hi, I'm Roy Marcillo (@GhostNet-Ops) 👋

### 💫 About Me

I am a 15-year-old student, developer, and aspiring **Ethical Hacker & Cyber Security Expert**. My playground is the terminal, and my absolute favorite environment is **Kali Linux**. I love exploring how networks work under the hood, finding vulnerabilities, and building custom security tools to make things smarter and safer.

Right now, I spend my time mastering **Python** for security scripting and automation, while diving deep into OSINT and penetration testing concepts. When I need a GUI, I build clean frontend web layouts using **HTML & CSS**. Armed with the **GitHub Education Student Pack**, I am constantly pushing my limits and currently expanding my tech stack to include **JavaScript, C#, SQL, and Assembly**.

### 🛠️ What I'm Up To & My Lab

- 🔬 **Current Projects:** I'm actively developing **PRISM-X** (an advanced C2 & Intelligence framework) and running a real-time **Red Alert Notification Bot** for local security alerts using Python and Azure virtual machines.
- 💻 **Hardware Geek:** Beyond software, I love building PCs (currently rocking a custom ASUS ROG desktop setup), upgrading hardware, and tinkering with microcontrollers like ESP32 and Arduino for physical security projects.
- ✈️ **Beyond the Keyboard:** I study at the Holtz Air Force High School, which fuels my massive passion for **fighter jets**. I'm also completely obsessed with motorsport, especially sports cars like the **BMW M4** and high-end motorcycles like the **M1000RR**.
- 🎮 **Downtime:** When I'm taking a break from coding or studying, you can catch me grinding FPS and simulation shooters like **CS2**, **Battlefield 6**, **Valorant**, **Warzone**, and **Ready or Not**.
- 🌌 **My Goal:** To become a top-tier expert in Cyber Security, OSINT, & Penetration Testing.
- 🧠 **Mindset:** *"Always curious, always learning."* I truly believe the best way to secure any system is to think exactly like the person trying to break it.
